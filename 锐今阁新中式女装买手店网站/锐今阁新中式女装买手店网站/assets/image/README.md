# 图片目录结构说明

本目录包含锐今阁网站所需的所有图片资源，按以下结构组织：

## 目录结构

```
assets/image/
├── shop/           # 门店空间相关图片
├── 春季/           # 春季服装图片
├── 夏季/           # 夏季服装图片
├── 秋季/           # 秋季服装图片
├── 冬季/           # 冬季服装图片
└── 新品/           # 新品服装图片
```

## 使用说明

1. 所有图片路径在代码中应使用相对于网站根目录的路径，例如：
   - `assets/image/shop/1.jpg`
   - `assets/image/春季/001.jpg`

2. 图片文件名应与产品数据文件中的路径保持一致

3. 如需添加新图片，请按照现有结构放置在相应目录中

4. 图片格式推荐使用JPG，以平衡质量和文件大小

5. 所有图片应经过适当压缩，以优化网站加载速度
