## 1. 引言

此文档定义了"柔古锐今，解构新生"品牌理念下的用户体验目标、信息架构、视觉设计语言及交互规范。本规范专注于桌面端浏览器的体验设计，并为纯HTML/CSS/JavaScript技术栈的实现提供详细指导，是连接产品需求与前端开发的桥梁。

## 2. 总体UX目标与原则

### 2.1 目标用户画像

1. **先锋探索者 (The Aesthetic Explorer)**
   - **核心特征**：28-35岁都市女性，艺术、设计或文化相关领域从业者/爱好者。她消费的不是商品，是"审美认同"和"文化叙事"。她拒绝刻板的中式符号，寻求具有智力挑战和情感共鸣的设计。
   - **与设计的关联**：她需要网站本身就是一个值得品味的"艺术品"，非线性导航、材质细节和深层文化故事能极大满足她的探索欲。

2. **精准收藏家 (The Conscious Collector)**
   - **核心特征**：35-40岁高收入女性，拥有成熟的个人风格。她关注服装的材质、剪裁工艺和独特性。她的决策理性，但容易被深刻的品牌哲学和卓越的实物展示所说服。
   - **与设计的关联**：她需要清晰、高质量的商品信息（尤其是材质特写），以及便捷的筛选和对比功能。网站的专业感和对细节的专注能建立她的信任。

### 2.2 关键可用性目标

- **审美沉浸**：90%的用户在首屏浏览后，能立即感知到"柔古锐今"的核心冲突美感，而非困惑。
- **探索效率**：用户能在 **15秒内** 通过非线性的导航方式（如时间轴、视觉网格）找到感兴趣的内容入口。
- **深度认知**：在单品页，用户能通过交互自然地发现"文化叙事"内容，完整理解设计故事的用户比例 > 70%。
- **行动清晰**：从产生兴趣到完成线下预约的关键路径，步骤明确，无认知障碍，表单完成时间 < 90秒。

### 2.3 核心设计原则

1. **解构而非破坏**：将传统元素（纹样、色彩、布局）拆解、抽象、重组，创造新颖但仍有根源的视觉形式。避免成为无意义的碎片堆砌。
2. **材质即语言**：将服装面料质感（丝绸的流光、棉麻的肌理）作为核心视觉与交互语言，通过CSS手段模拟触觉联想。
3. **冲突制造张力**：在布局（对称vs非对称）、字体（书法vs无衬线）、动效（水墨晕开vs机械精密）中刻意制造可控的对比，以视觉张力诠释品牌哲学。
4. **叙事引导交互**：用户的浏览路径应像阅读一首朦胧诗或探索一个空间，有预设的情绪节奏和惊喜的发现点，而非线性的工具流程。
